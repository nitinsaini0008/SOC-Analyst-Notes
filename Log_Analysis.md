# Log Analysis

## About

Log Analysis is the process of collecting, examining, and interpreting log data generated by operating systems, applications, network devices, and security tools to identify suspicious activities, troubleshoot issues, and investigate security incidents.

For a SOC Analyst, log analysis is one of the most important daily responsibilities.

---

# What is a Log?

A log is a record of events generated by a system or application.

Examples

- User Login
- Failed Login
- File Access
- Software Installation
- Network Connection
- Firewall Action

---

# Why Log Analysis is Important

Log analysis helps organizations to:

- Detect Security Threats
- Investigate Incidents
- Troubleshoot Problems
- Monitor User Activity
- Meet Compliance Requirements
- Identify Insider Threats

# Log Structure

A typical log contains:

- Timestamp
- Source IP
- Destination IP
- Username
- Event ID
- Severity
- Action
- Status
- Message

Example

```
2026-08-02 10:15:34

User: admin

Source IP: 192.168.1.10

Event ID: 4624

Status: Success

Message:
Successful Logon
```

- Login from Foreign Country
- Impossible Travel

# Real-Life Example

A SOC Analyst receives an alert for multiple failed login attempts.

Investigation shows:

- 50 failed logins within 5 minutes.
- One successful login immediately afterward.
- The account accesses sensitive files.

The analyst reviews Windows Security logs, firewall logs, and Active Directory logs, confirms a brute-force attack, disables the compromised account, and escalates the incident for further investigation.
