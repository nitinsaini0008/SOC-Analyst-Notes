# Windows Event Logs

## About

Windows Event Logs are records generated by the Windows operating system and applications to track system activities, user actions, security events, and errors. These logs are one of the primary data sources used by SOC Analysts to investigate security incidents.

Windows Event Viewer is the built-in tool used to view and analyze these logs.

---

# What are Windows Event Logs?

Windows Event Logs record important events such as:

- User Logins
- Failed Logins
- File Access
- Software Installation
- Service Changes
- System Startup
- System Shutdown
- Security Events

These logs help security analysts investigate suspicious activities and detect cyber attacks.

---

# Main Log Categories

## 1. Application Log

Contains events generated by applications.

Examples

- Application Errors
- Software Crashes
- Database Errors

---

## 2. Security Log

Records authentication and authorization events.

Examples

- Successful Logins
- Failed Logins
- Account Lockouts
- Privilege Changes

Most important log for SOC Analysts.

---

## 3. System Log

Contains operating system events.

Examples

- Driver Loading
- Windows Updates
- Service Start/Stop
- Hardware Issues

---

## 4. Setup Log

Records installation-related events.

Examples

- Windows Installation
- Feature Updates
- Driver Installation

---

## 5. Forwarded Events

Stores logs received from remote Windows systems using Windows Event Forwarding (WEF).

# Common Security Investigations

## Brute Force Attack

Look for:

```
Many Event ID 4625

↓

One Event ID 4624

↓

Possible Account Compromise
```

---

## New Administrator Account

Look for:

- Event ID 4720
- Event ID 4728
- Event ID 4732

---

## Privilege Escalation

Indicators

- User Added to Administrators Group
- New Administrative Login
- Privileged Account Creation

---

## Account Lockout

Relevant Event IDs

- 4625
- 4740

May indicate:

- Password Guessing
- Brute Force Attack

# Best Practices

- Monitor Security Logs Daily
- Investigate Repeated Failed Logins
- Review Privileged Account Activity
- Monitor Account Creation Events
- Enable Log Forwarding
- Synchronize Time Using NTP
- Retain Logs According to Policy
- Export Logs Before Major Investigations

---

# Real-Life Example

A SOC Analyst receives an alert about unusual administrator activity.

Investigation shows:

- Multiple **4625** failed logons.
- One **4624** successful logon.
- Event **4728** indicates the compromised account was added to the Administrators group.

The analyst disables the account, collects logs, and escalates the incident to the Incident Response team.
