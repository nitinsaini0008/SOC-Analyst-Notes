# Network Log Analysis

## About

Network Log Analysis is the process of examining logs generated by network devices and security solutions to identify suspicious activities, detect cyber attacks, troubleshoot connectivity issues, and investigate security incidents.

SOC Analysts use network logs daily to detect malicious traffic, unauthorized access, lateral movement, data exfiltration, and network-based attacks.

---

# What are Network Logs?

Network logs are records generated by networking devices and applications that capture communication between systems.

Examples include:

- Firewall Logs
- Router Logs
- Switch Logs
- VPN Logs
- IDS/IPS Logs
- DNS Logs
- Proxy Logs
- NetFlow Logs

---

# Why Network Log Analysis is Important

Network Log Analysis helps organizations:

- Detect Cyber Attacks
- Monitor Network Activity
- Investigate Security Incidents
- Detect Data Exfiltration
- Identify Lateral Movement
- Improve Network Visibility

# Common Log Fields

| Field | Description |
|--------|-------------|
| Timestamp | Date and Time |
| Source IP | Sender IP |
| Destination IP | Receiver IP |
| Source Port | Source Port Number |
| Destination Port | Target Port |
| Protocol | TCP, UDP, ICMP |
| Action | Allow or Block |
| Username | Authenticated User |
| Device | Log Source |

# Common Network Attacks

## Port Scanning

Indicators

- Multiple Destination Ports
- Same Source IP
- Short Time Period

---

## Brute Force Attack

Indicators

- Multiple Failed Logins
- Same Source IP
- Authentication Failures

---

## Data Exfiltration

Indicators

- Large Outbound Traffic
- Unknown Destination
- Unusual Transfer Time

---

## DNS Tunneling

Indicators

- Long DNS Queries
- High Number of Requests
- Unknown Domains

---

## Lateral Movement

Indicators

- SMB Traffic
- RDP Connections
- PsExec Activity
- Remote PowerShell

---

## Command and Control (C2)

Indicators

- Repeated Connections
- Unknown External IP
- Regular Beaconing Pattern

# Real-Life Example

A SOC Analyst receives an alert about unusual outbound traffic.

Investigation shows:

- Multiple connections to an unknown external IP.
- Large data transfers outside business hours.
- DNS queries to suspicious domains.
- Repeated HTTPS connections every five minutes.

The analyst confirms Command and Control (C2) communication, blocks the malicious IP address, isolates the affected endpoint, and escalates the incident for further investigation.
